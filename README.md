# 🩸 MiDi Code - موقع الأنمي الدموي الاحترافي

موقع تفاعلي حصري بطلب من المالك مع نظام حماية وصلاحيات كاملة لمالك الموقع فقط لتعديل خلايا الأنمي ورموز الفيديوهات الثابتة.

## 🚀 طريقة الرفع على GitHub Pages:
1. ارفع ملف `index.html` إلى مستودعك الجديد على **GitHub**.
2. من إعدادات المستودع (Settings -> Pages) قم بتفعيل النشر من فرع `main`.
